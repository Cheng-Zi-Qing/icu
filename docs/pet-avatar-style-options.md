# 桌宠形象风格方案

## 技术栈说明
所有方案都在 macOS 桌面端原生实现，无需外部依赖，基于：
- **AppKit NSBezierPath** — 矢量路径绘制
- **Core Graphics** — 渐变、阴影、混合模式
- **CALayer** — 层叠、变换、动画
- **CAShapeLayer** — 矢量形状硬件加速

---

## 方案 1：Q弹水滴生物 🌊（推荐）

**风格**：柔软Q弹、半透明、极简可爱  
**灵感**：史莱姆、水滴、果冻

### 视觉特征
- **身体**：圆润水滴形状，渐变填充（浅蓝→深蓝），半透明 85%
- **眼睛**：两个黑色椭圆，会跟随鼠标转动，带白色高光
- **嘴巴**：简单弧线，表情可变（开心/惊讶/困倦）
- **材质**：果冻质感，边缘有白色高光描边
- **阴影**：柔和模糊阴影，随呼吸变化

### 动画表现
- **呼吸**：整体缩放 + 轻微上下浮动，像在水里漂
- **点击**：squash & stretch 形变，像果冻被戳
- **拖拽**：拉长变形，松手后回弹晃动
- **悬停**：微微膨胀，眼睛看向鼠标
- **表情**：眨眼时整个身体微微压扁

### 技术实现
```
NSBezierPath 绘制水滴轮廓
→ CAGradientLayer 渐变填充（径向渐变）
→ CAShapeLayer 眼睛（可独立变换）
→ 白色描边 + 内阴影模拟透明质感
```

## 方案 2：圆滚滚毛球 🐹

**风格**：毛茸茸、温暖、治愈系  
**灵感**：仓鼠、龙猫、毛球玩具

### 视觉特征
- **身体**：圆形，用放射状短线模拟绒毛纹理
- **颜色**：米黄/浅棕渐变，边缘暗一点形成球体感
- **眼睛**：黑豆眼 + 白色高光，眯眼时变成 "^_^"
- **耳朵**：两个小半圆，会随动作微微摆动
- **腮红**：粉色圆形，透明度 30%
- **手脚**：极简小短手，只在特定动作出现（挠头/招手）

### 动画表现
- **呼吸**：毛发纹理轻微扩散/收缩，模拟蓬松感
- **点击**：整体压扁 + 毛发炸开
- **高兴**：耳朵竖起 + 眼睛弯成月牙
- **困倦**：眼睛眯成一条线 + 头微微下垂
- **打哈欠**：嘴巴张大 + 身体抖动

### 技术实现
```
NSBezierPath 圆形身体
→ 径向渐变模拟球体
→ 随机短线绘制毛发纹理（每根毛发是独立路径）
→ CAShapeLayer 叠加耳朵/眼睛/腮红
→ 纹理随缩放动态重绘
```

## 方案 3：像素艺术升级版 🎮

**风格**：复古像素 + 现代渲染  
**灵感**：8-bit 游戏，但用矢量重绘

### 视觉特征
- **身体**：保留像素风格，但用矢量方块拼接（不再是位图）
- **颜色**：鲜艳对比色，带CRT显示器扫描线效果
- **眼睛**：2×2像素方块，闪烁时整块亮起
- **动作**：每帧是独立姿态，但过渡是平滑插值的（打破传统像素风硬切）

### 动画表现
- **移动**：像素块"流动"过渡，不是瞬移
- **攻击**：发射像素方块弹幕
- **受击**：闪烁 + 像素炸裂成小方块再重组

### 技术实现
```
CAShapeLayer 拼接小方块（每个是独立layer）
→ 方块位置用 spring 动画过渡
→ CIFilter 叠加扫描线/色差效果
→ 支持导入传统像素图，自动转换为矢量方块
```

## 方案 4：极简几何图形 ⚪️

**风格**：设计感、现代、冷淡风  
**灵感**：Material Design、iOS 图标、抽象艺术

### 视觉特征
- **身体**：纯几何形（圆形/方形/三角形组合）
- **配色**：单色或双色，跟随系统主题（亮色/暗色模式）
- **眼睛**：两个点，极简
- **线条**：粗细渐变的描边，不填充
- **光影**：长投影 + 渐变叠加，扁平但有层次

### 动画表现
- **变形**：圆形↔方形↔三角形平滑变形
- **状态切换**：形状+颜色同步变化（idle=圆，working=方，focus=三角）
- **交互**：点击时形状炸裂成小几何块再重组

### 技术实现
```
CAShapeLayer path 插值变形
→ CAGradientLayer 叠加渐变
→ CATransform3D 模拟长投影
→ 响应 NSAppearance 切换配色
```

## 方案 5：3D球体（伪3D光照）🌍

**风格**：立体感、科幻、高级  
**灵感**：玻璃球、水晶球、星球

### 视觉特征
- **身体**：球体，用径向渐变 + 高光模拟3D
- **材质**：玻璃/金属/塑料可切换
- **高光**：左上角白色高光 + 右下暗部
- **反射**：底部有模糊倒影
- **眼睛**：嵌入球体表面，有透视变形

### 动画表现
- **旋转**：球体自转，高光位置固定（模拟光源不动）
- **鼠标跟随**：球体表面法线跟随鼠标，高光动态移动
- **点击**：涟漪扩散（像水面）
- **材质变化**：玻璃→金属→塑料 过渡

### 技术实现
```
径向渐变模拟球体
→ CALayer mask 裁剪高光形状
→ 高光位置根据鼠标角度实时计算
→ CIFilter 高斯模糊做倒影
→ 不用 SceneKit，纯 2D 技术伪 3D
```

## 方案 6：液态金属 🌊💧

**风格**：流动、炫酷、未来感  
**灵感**：水银、液态金属终结者

### 视觉特征
- **身体**：不规则液态形状，边缘不断波动
- **材质**：金属光泽 + 镜面反射效果
- **颜色**：银色渐变，边缘有彩虹色光泽（像汽油膜）
- **形态**：随状态改变形状（idle=水滴，working=拉长，alert=尖刺）

### 动画表现
- **流动**：边缘持续波动，用 Perlin 噪声驱动
- **变形**：状态切换时液体流淌到新形状
- **分裂/融合**：点击时分裂成小液滴再融合
- **反射**：表面反射桌面颜色（取屏幕像素采样）

### 技术实现
```
CAShapeLayer path 用正弦波 + 噪声生成
→ CAGradientLayer 金属渐变
→ CIFilter 镜面效果
→ 每帧重新计算路径（60fps）
→ 屏幕采样用 CGWindowListCreateImage
```
